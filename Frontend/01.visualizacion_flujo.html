🌟 TAI - Flujo de Integración

Visualización del sistema de reportes en tiempo real

📊 Flujo General del Sistema

👤
1. Paciente Escribe Mensaje
El usuario escribe un mensaje en el chatbot de TAI
chatbot_updated.html → userInput.value = "Estoy en peligro"
↓
🔄
2. Frontend Envía a Backend
JavaScript envía el mensaje al servidor
POST /chat → {mensaje, usuario_id}
↓
🤖
3. Backend Procesa & Detecta Crisis
Flask procesa el mensaje con IA y detecta nivel de severidad
nivel_escalamiento = 3 (CRISIS)
↓
📨
4. Backend Envía Reporte
Si es crisis, guarda alerta en BD y notifica al profesional
INSERT alertas_criticas → profesional_id, usuario_id, datos
↓
👨‍⚕️
5. Profesional Recibe Alerta
El dashboard hace polling y recibe la alerta en tiempo real
GET /profesional/alertas?profesional_id=prof_001
↓
✅
6. Profesional Actúa
Hace click en "Enter" para aceptar el caso y ayudar al paciente
POST /profesional/alertas/confirmar

🧩 Componentes de la Solución

📜
tai_reporte_integracion.js
Módulo JavaScript que maneja toda la lógica de integración. Define tres clases principales:
TAIReporteManager
TAIUserFlow
TAIProfesionalFlow
💬
chatbot_updated.html
Interfaz del paciente. Utiliza TAIUserFlow para enviar mensajes y reportes automáticamente cuando detecta crisis.
const userFlow = new TAIUserFlow();
📊
dashboard_profesional_updated.html
Interfaz del profesional. Utiliza TAIProfesionalFlow para monitorear alertas en tiempo real.
const profesionalFlow = new TAIProfesionalFlow(id);
🔌
Backend Endpoints
Tres nuevos endpoints en Flask que manejan el envío, recepción y confirmación de alertas.
POST /reportes/enviar
GET /profesional/alertas
POST /profesional/alertas/confirmar
💾
Base de Datos
Tabla alertas_criticas que almacena todos los reportes de crisis vinculados entre paciente y profesional.
usuario_id, profesional_id,
tipo_alerta, estado
⚙️
Polling en Tiempo Real
El dashboard hace GET cada 5 segundos para recibir nuevas alertas. Configurable en milisegundos.
iniciarPollAlertas(callback, 5000)
